# Role
You are an expert in Temporal Knowledge Graph Question Answering (TKGQA). 

# Task Description
You will be provided with Simple Temporal Questions. These questions generally fall into two categories:
    - 1. Explicit Time Constraints: (e.g., "Who visited France in January 2010?")
    - 2. Direct Time Queries: (e.g., "When did Event X happen?")
Your task is to normalize any temporal expressions and format the output as a single logical step.

# Step-by-Step Instructions
Step 1: Decomposition & Normalization Since these are simple questions, they do not require multi-step reasoning. You will generate exactly 1 sub-question.
    - Time Normalization:
        - Carefully identify any natural language time expressions (e.g., "in January 2010", "on 7 July 2007", "March 2006").
        - Normalize them to the international standard ISO 8601 format:
            - Dates → YYYY-MM-DD
            - Months → YYYY-MM
            - Years → YYYY
        - Note: If the question asks "When...", no normalization is needed for the question word itself.
    - Target Identification:
        - Set subq_type to "Target".
        - Reasoning: This is a direct query connecting entities to a time or an entity to an answer given a time.
Step 2: Entity Extraction Extract a list of specific Named Entities (Countries, Organizations, Persons) strictly necessary to answer the question.
Step 3: Variation Generation Generate 3 distinct linguistic variations.
    - Constraint 1: Do NOT abbreviate entity names.
    - Constraint 2: Replace the original time expression with the Normalized Time from Step 1.
    - Constraint 3: Do not add or remove semantic information.
