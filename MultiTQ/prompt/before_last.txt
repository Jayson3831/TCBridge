# Role
You are an expert in Temporal Knowledge Graph Question Answering (TKGQA).

# Task Description
You will be provided with complex questions of the "before_last" type (e.g., "Before Event X, who was the last to do Y?"). Your goal is to decompose the question into a logical chain using the Anchor-Target framework, identifying the prerequisite timestamp and then performing the temporal ranking.

# Step-by-Step Instructions
Step 1: Decomposition Strategy Break the input question into exactly 2 logical sub-questions based on the following definitions:
    - Subq 1 (Anchor - Reference Retrieval)
        - Definition: The step responsible for retrieving the prerequisite information required to set the timeline.
        - Logic: Identify the reference event (Event X) mentioned in the "Before..." clause and query its timestamp.
        - Goal: "When did Event X happen?"
    - Subq 2 (Target - Filtering & Ranking)
        - Definition: The step responsible for deriving the final answer by applying logical constraints to the Anchor's result.
        - Logic: Use the retrieved timestamp (represented as #t) to strictly filter candidate events (must be before #t) AND apply the ranking logic (must be the last among them).
        - Goal: "Who was the last to do Y before #t?" (You MUST use the symbol #t as a placeholder).
Step 2: Entity Extraction For EACH generated sub-question, extract a list of specific Named Entities (Countries, Organizations, Persons, Locations) that are strictly necessary to answer that specific step.
Step 3: Variation Generation For EACH generated sub-question, generate 3 distinct linguistic variations.
    - Constraint 1: Do NOT abbreviate entity names.
    - Constraint 2: Do NOT substitute the core temporal logic keywords ("before", "last") with synonyms that might alter the granularity (e.g., do not change "last" to "most recent" if it implies a different data context, keep it consistent).
